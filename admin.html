홈페이지 관리

저장하면 1~2분 뒤 홈페이지에 반영됩니다.

1. 연결 설정 (처음 한 번)

GitHub 저장소 정보와 토큰을 입력합니다. 토큰은 이 휴대폰 브라우저에만 저장되고 홈페이지에는 올라가지 않습니다.

지금은 '검토 모드'입니다. 공개 동의가 확인되지 않은 영상도 홈페이지에 보입니다. 정식 공개 전 아래 '공개 설정'에서 끄세요.
2. 강습 영상

종목별로 위에 있는 영상 2개가 홈페이지 스키·스노보드 영역에 나오고, 나머지는 '전체 영상 보기'에 들어갑니다.

3. 공지·이벤트
4. 고객 후기

실제 후기만, 작성자의 게시 동의를 받은 뒤 입력하세요.

5. 예약 링크·연락처
6. 요금·시간표·환불

비어 있는 항목은 홈페이지에 나오지 않습니다.

7. 추가 안내 (FAQ·만남 장소·강사진·사업자)
8. 사진 교체

사진을 고르면 휴대폰에서 자동으로 줄여서 바로 올립니다. 저장 버튼과 별개로 즉시 반영됩니다.

9. 공개 설정

정식 공개 전 반드시 끄세요. 끄면 '보호자 공개 동의'를 확인한 영상만 보입니다.
